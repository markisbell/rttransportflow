# Economy balancing — constants, rationale, measured windows

Family rule (infrastruct `tools/balancing` pattern): **change a constant →
rerun `--smoke=economy` → commit both** this doc's source constants
(`data/catalogs/economy.json`) and the regenerated
[`economy_windows.csv`](economy_windows.csv).

## Where the constants live

Every economic constant is in `data/catalogs/economy.json`, each block with
its `_rationale`. Authority for the values: docs/PARAMETERS.md §1 (per-tech
capex/O&M/fuel/efficiency), §4 (merit order at 30 €/t CO2), and
docs/GAME_DESIGN.md §3.4 (tariff / VoLL / reserve remuneration / loans).

## Design intents the windows guard

| Intent | Guarded by |
|---|---|
| Merit order emerges: nuclear < lignite < coal < CCGT < OCGT | `dispatch_day` smoke: nuclear base-loaded, gas peaking, evening price > night price |
| Billing on DELIVERED energy (blackouts cost revenue) | `economy` smoke: ledger-consistency check (Δtreasury reproduces the books to < 1 €) |
| A real grid costs billions before it earns | `economy` smoke: capex_charged window |
| System cost lands in a believable band | avg_cost ∈ (10, 300) €/MWh window |
| Carbon intensity is physical | co2_intensity ∈ (20, 900) g/kWh window |
| Scarcity is felt, not narrated | `calm_week` smoke: forced Dunkelflaute → scarcity blocks + frequency sag on a wind-heavy build |

## Measured windows

`economy_windows.csv` is regenerated by `--smoke=economy` (a simulated day
on the auto-built demo grid, seed 42). Do not hand-edit it. If a constant
change moves a window outside the smoke's bounds, either the constant or the
bound is wrong — decide consciously and record it here.

## Known P6 simplifications (each documented in code)

- Startup cost uses the single warm value per kind; min-up/down times are
  enforced physically by the engine's start sequences, not economically.
- FCR withholding is a flat 8 % headroom cap on committed thermal; the
  reserve payment assumes the procurement target (not measured headroom).
- Connection-bay fees are not yet billed (arrives with transformer bays).
